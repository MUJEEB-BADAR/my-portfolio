# Personal Portfolio Website

A personal portfolio website built with PHP, MySQL, HTML, CSS, and JavaScript to showcase my profile, skills, and web development projects.

## Features

- Responsive portfolio website
- About and contact pages
- Projects listing and project details
- Admin login and project management
- Add, update, and delete projects
- Contact form
- CV download functionality
- Session and CSRF protection for relevant admin actions

## Technologies Used

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- Git and GitHub

## Local Setup

1. Install [XAMPP](https://www.apachefriends.org/).
2. Clone or download this repository into the `htdocs` directory.
3. Create a MySQL database for the project using phpMyAdmin.
4. Configure your local database connection in `includes/db.php`.
5. Configure the website settings in `includes/config.php`.
6. Import the database schema and create an admin account using your local setup process.
7. Start Apache and MySQL from the XAMPP Control Panel.
8. Open `http://localhost/my-portfolio/` in your browser.

**Note:** The database schema and local configuration files are not included in this repository yet. The setup steps may need adjustment before another developer can run the project.
